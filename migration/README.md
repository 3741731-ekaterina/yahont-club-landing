# Клуб Яхонт на Тильде

16.10.2026 основная страница https://yahontovafinance.ru/club_yahont переведена с iframe Vercel на пять собственных HTML-блоков T123. ID основной страницы: 153834946, проект: 5252749. Адрес, настройки страницы и шесть виджетов GetCourse сохранены.

## Обновление

Править исходные `index.html`, `october.css`, `club.js`, `utm.js`. Затем выполнить из корня репозитория:

```sh
python3 scripts/build-tilda.py
```

Генератор создаёт `migration/t123-01.html` … `t123-05.html` в порядке установки в Tilda. Каждый блок меньше 60 КБ; вставлять весь `tilda-t123-code.html` в один T123 нельзя из-за ограничения Тильды. Перед публикацией обновить все пять блоков.

Все 24 изображения и видео находятся на static.tildacdn.com; соответствие исходных файлов и URL — `assets.json`. Новые медиа сначала загрузить в Тильду, затем добавить в эту таблицу. Видео сохранено целиком (32,30 с, 1924×1080), сжато до 2,9 МБ для лимита загрузки Тильды 5 МБ. Исходник видео остаётся в корне репозитория.

Страница 311249909 использована для загрузки медиа и проверки переноса. Её галерея и видеоблок хранят ссылки на файлы; в опубликованном макете они скрыты. Не удалять хранилище медиа без проверки ссылок.

`migration/tilda-before.html` — резервная копия опубликованной страницы до переноса. Для отката достаточно вернуть прежнюю iframe-вставку из этой копии и убрать остальные четыре T123. Vercel и GitHub не удалены.

## Проверка

`tests/tilda-migration.cjs` проверяет опубликованный адрес: отсутствие запросов к Vercel, UTM во всех шести виджетах, загрузку изображений, раскрытие девяти курсов, галерею отзывов, отсутствие горизонтальной прокрутки на пяти разрешениях и совпадение нижних границ плашек первого экрана. Формы не отправляются, покупки не совершаются.

```sh
CLUB_TEST_URL=https://yahontovafinance.ru/club_yahont node tests/tilda-migration.cjs
```

Для установленного вне проекта Playwright указать путь через `PLAYWRIGHT_MODULE`.
